Privacy Controls & Hybrid DBMS Architecture

Public vs. Private Data Boundary

• Public Listings: Title, category, approximate zone, general description, and photo metadata.
• Private Claims: Claimant secret descriptions and personal contact details are stored in MySQL with restricted foreign key access, never sent to public search endpoints or AI prompts.

How MySQL and MongoDB Collaborate

• MongoDB (Document Store): Holds flexible, nested item reports (e.g. nested_attributes, location, urgency_info).
• MySQL (Relational ACID): Holds audit tables (users, claims, match_suggestions, notifications, handoffs) with transactions, snapshots, and foreign keys.
• Bridge: Connected via stable shared identifier item_uuid.
